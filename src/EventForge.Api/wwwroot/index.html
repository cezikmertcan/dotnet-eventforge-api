EventForge is a production-minded backend example for venues, events, speakers, sessions, and registrations. Explore the OpenAPI contract or check the service readiness endpoints.

Document relationships

MongoDB references connect events to venues, sessions to speakers, and registrations to attendees.

Role-based access

JWT tokens distinguish Admin, Organizer, and Attendee capabilities without exposing ownership fields to clients.

Cache-aware reads

Redis accelerates list and detail reads while writes invalidate affected keys and fall back safely if cache is unavailable.

Operational by default

Health checks, structured ProblemDetails, security headers, rate limiting, Docker, and CI are part of the example.
